# Contributing to Sexy S-Pen

Thank you for taking an interest in Sexy S-Pen. Forks, experiments, bug reports, documentation improvements, accessibility work, packaging fixes, and new Surface Pen support are welcome.

## Fork respectfully

Please treat the project and its contributors with respect. If you fork Sexy S-Pen, keep the original project link, copyright notices, license, image attributions, and meaningful credit to **pfn000** intact. A short note in your fork’s README such as “Based on Sexy S-Pen by pfn000” is appreciated.

GitHub’s fork mechanism and the GPL-3.0-or-later license allow people to study, modify, and redistribute the code under the license terms. This community request is not intended to override those rights. If you plan to publish a substantially renamed or redistributed derivative, please contact the maintainer first so we can avoid confusion, coordinate improvements, and make sure the original project receives clear credit.

## Good sportsmanship

Please open issues with useful reproduction details, identify your Surface Pen model and Linux input stack where possible, and avoid presenting unsupported hardware capabilities as confirmed facts. Pull requests should explain what changed, why it is needed, and how it was tested. Do not include private keys, personal data, unlicensed product artwork, or arbitrary privileged commands.

## Attribution and branding

Do not imply that a fork is the official Sexy S-Pen project unless it is maintained in this repository or explicitly authorized by the maintainer. If you change the application name, visual identity, package name, or release channel, clearly describe the relationship to the original project. Preserve the GPL license and follow the attribution notes for the supplied pen images in `docs/assets/README-image-sources.md`.

## Contact

The primary project is maintained at [github.com/pfn000/sexy-s-pen](https://github.com/pfn000/sexy-s-pen). Please open an issue for public technical discussion or contact the maintainer through the GitHub profile before launching a substantially renamed public derivative.
